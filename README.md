# Chess

Two-player Art Deco chess for iOS, built with SwiftUI.

Stage 1: board, starting position, theme, icon.
Stage 2: selection, legal move highlights, standard piece movement, turns.
Stage 3: castling, en passant, promotion to queen, castling rights.
Stage 4: checkmate, stalemate, game-over lock, reset.
Stage 5: polish: last-move and check highlights, capture markers, coordinates, move history, smoother reset.
